ALFAPOS — Windows (x64)

TAVSIYA — o'rnatuvchi:
1. alfapos_app-windows-x64-setup.exe ni ishga tushiring.
2. O'rnatish tugagach Start yoki ish stolidan AlfaPOS ni oching.
   Barcha fayllar (exe, dll, data\) avtomatik o'rnatiladi.

ZIP (portativ):
1. ZIP ni to'liq oching (masalan: C:\Alfapos\).
2. alfapos_app.exe ni shu papkadan ishga tushiring.
   MUHIM: exe ni boshqa joyga yolg'iz ko'chirmang — yonidagi .dll va data\ papkasi kerak.
3. Birinchi marta Windows Firewall so'rasa — «Ruxsat berish» (Private va Public).
4. Antivirus exe ni bloklasa — istisno qo'shing.
5. Kirish: Kompaniya ID, login, parol (app.alfapos.uz serveri).

Agar tarmoq xatosi chiqsa:
- Internet va vaqtni tekshiring
- VPN/proksini o'chiring
- windows\scripts\allow_alfapos_firewall.ps1 ni administrator sifatida ishga tushiring

Telefon orqali chop etish (Mobil relay):
1. AlfaPOS ochiq, Sozlamalar → Termal printer → «Mobil relay» Faol (port 9100).
2. Firewall skripti inbound TCP 9100 ni ham ochadi (telefon → kompyuter).
3. Telefon va kompyuter BIR XIL WiFi da.
4. Telefonda: Printer sozlamalari → WiFi yoqilgan → «Kompyuter relay» →
   desktopdagi IP + port 9100 → Saqlash → Ulanishni tekshirish.
5. Agar «Printer topilmadi» chiqsa — firewall inbound 9100 yoki WiFi izolatsiyasi.

Versiya: pubspec.yaml dagi version maydoni.
